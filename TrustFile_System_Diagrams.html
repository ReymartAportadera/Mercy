System Architecture Diagram

System Workflow Diagram

Step-by-step scan execution: Client file ingestion → Three-engine analysis → Consensus override → Firebase persistence → Interactive report

🧮 Deterministic Scoring Formula (Global Consensus Override)
Final_Risk_Score =
   if (VT_Engines ≥ 20 AND VT_Positives == 0) → min(Heuristic_Score, 40) ← Global Consensus Cap
   if (VT_Positives > 0) → max(Heuristic_Score, (VT_Positives / VT_Engines) × 100)
   else → Heuristic_Score
